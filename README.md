# DIO_ProjetoXBox
Dashboard interativo desenvolvido em Excel para análise de vendas, faturação e métricas de subscrição do ecossistema Xbox Game Pass.


🎮 Dashboard Xbox Game Pass
Um dashboard interativo construído em Microsoft Excel para monitorizar e analisar o desempenho de vendas e as métricas de subscrição do ecossistema Xbox Game Pass.

🎯 Sobre o Projeto
Este projeto transforma dados brutos de vendas numa interface visual intuitiva. O objetivo principal é responder a perguntas vitais de negócio, como o apuramento da faturação total, a análise do impacto das renovações automáticas e a venda de pacotes adicionais.

🗂️ Estrutura do Ficheiro
O ficheiro (Dashboard_Xbox_Feito.xlsx) está organizado em 4 separadores práticos:

A̳ssets: Paleta de cores e recursos visuais.

B̳ases: Tabela de dados brutos (~300 registos de 2024), contendo os detalhes das subscrições (Planos, Preços, Add-ons como EA Play e Minecraft).

C̳álculos: O "motor" da análise com tabelas dinâmicas para agregar os valores.

D̳ashboard: O painel visual interativo final.

🚀 Como Utilizar
Faça o download do ficheiro Dashboard_Xbox_Feito.xlsx neste repositório.

Abra-o utilizando o Microsoft Excel (recomenda-se a versão 2019 ou Microsoft 365).

Navegue até ao separador D̳ashboard para explorar os gráficos e interagir com os filtros de dados.

Quer testar os seus próprios dados? Adicione novas linhas no separador B̳ases, vá ao menu Dados (Data) no Excel e clique em Atualizar Tudo (Refresh All).
